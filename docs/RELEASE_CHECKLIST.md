# Release Checklist

## Product

- Core anonymous bottle flow works without backend errors.
- Report/block works from bottle and reply screens.
- AI Lighthouse is labeled and has crisis safeguards.
- Paid virtual items use native in-app purchases and server receipt validation.
- Physical redemptions have policies, address handling, and support flow.

## App Store / Play Store

- App name, subtitle, descriptions, screenshots, and keywords prepared.
- Privacy policy URL available.
- Terms of service URL available.
- Account deletion path documented and available in app.
- User-generated content moderation notes prepared for review.
- Age rating reviewed for anonymous social content.

## Technical

- EAS production builds pass.
- iOS bundle identifier and Android package are final.
- Push notification entitlement and FCM/APNs setup complete.
- Crash reporting configured.
- Analytics avoids collecting sensitive message content.
- Accessibility checks complete.
- Device QA on small iPhone, large iPhone, common Android phone, and tablet.
